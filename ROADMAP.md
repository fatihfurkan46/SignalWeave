# Roadmap

SignalWeave weaves heterogeneous AI workflow telemetry into a single, portable
fabric. The milestones below track the capabilities that are shipped today.

## Implemented milestones

- [x] Common signal model with vendor-agnostic normalization adapters
- [x] Deterministic run aggregation with quality and reliability indicators
- [x] Portable text and JSON weave reports with fabric-wide rollups
- [x] Native C++17 aggregation core with Python/native parity

## Exploration

The following directions are under consideration for future iterations and are
not part of the current shipped surface:

- Streaming ingestion for long-running sessions
- Additional first-party framework adapters
- Comparative diffing between two fabrics
- Optional HTML report surface built on the same aggregate
