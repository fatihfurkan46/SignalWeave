# Roadmap

SignalWeave weaves heterogeneous AI workflow telemetry into a single, portable
fabric. The milestones below track the capabilities that are shipped today.

## Implemented milestones

- [x] Common signal model with vendor-agnostic normalization adapters
- [x] Deterministic run aggregation with quality and reliability indicators
- [x] Portable text and JSON weave reports with fabric-wide rollups
